# 🚀 University Lab Report Automation Engine (MERN-to-PDF)
### Production-Grade System Blueprint & Roadmap

This project automates the manual creation of university lab reports by transforming raw source code files (**JavaScript, Python, C, Assembly**) and their runtime terminal outputs into pixel-perfect, professionally styled PDFs—eliminating the need for manual copy-pasting into tools like Canva.
